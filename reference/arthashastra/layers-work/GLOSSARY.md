# Glossary: fixed renderings for every chunk (reviewers extend; drafters only read)

- dharma = dharma (धर्म); karma = action (कर्म); ṛṣi = sage (ऋषि)
- rājan = O king (हे राजन्); bhārata = O Bhārata (हे भारत); tāta = dear one (तात)
- Names in English: plain letters without diacritics (Kautilya, Indra, Manu).
- Arthashastra terms are added below by the reviewer as they come up.
- prakṛti = constituent element (प्रकृति); sampat (X-sampat) = excellence of X (X की सम्पत्)
- the seven prakṛtis: svāmin = king (स्वामी), amātya = minister (अमात्य), jana-pada = country (जनपद), durga = fort (दुर्ग), kośa = treasury (कोश), daṇḍa = army (दण्ड), mitra = ally (मित्र); amitra/ari/śatru = enemy (अमित्र/शत्रु)
- ātmavān = self-possessed (आत्मवान्); anātmavān = not self-possessed (अनात्मवान्); naya = policy (नीति)
- dharma-adhigata = acquired through dharma (धर्मपूर्वक अर्जित)
- Hindi: no bracketed glosses inside the translation; put explanations in `notes`.
- (6.2) yoga = acquisition (योग); kṣema = security (क्षेम); śama = peace (शम); vyāyāma = activity (व्यायाम); ṣāḍguṇya = the sixfold policy (षाड्गुण्य)
- (6.2) daiva = the divine (दैव); mānuṣa = the human (मानुष); aya/anaya = good fortune/misfortune (अय/अनय); naya/apanaya as a pair = good policy/bad policy (नय/अपनय)
- (6.2) vijigīṣu = the conqueror (विजिगीषु); madhyama = the middle king (मध्यम); udāsīna = the neutral king (उदासीन); pārṣṇi-grāha = the heel-seizer (पार्ष्णिग्राह); ākranda = the rear ally (आक्रन्द); āsāra = reinforcer (आसार); dūṣya = the treasonable (दूष्य)
- (6.2) śakti = power (शक्ति); siddhi = success (सिद्धि); mantra-/prabhu-/utsāha-śakti = power of counsel/lordship/energy (मन्त्र-/प्रभु-/उत्साहशक्ति); maṇḍala = circle (मण्डल); sahaja/kṛtrima = inborn/artificial (सहज/कृत्रिम)
- (10.1) skandhāvāra = the camp (स्कन्धावार); nāyaka = the nāyaka (नायक); vardhaki = carpenter (वर्धकि); mauhūrtika = astrologer (मौहूर्तिक); praśāstṛ = the praśāstṛ, camp superintendent (प्रशास्ता); viṣṭi = the labour corps (विष्टि); śreṇī (troops) = guild troops (श्रेणी-सैन्य); maula/bhṛta = hereditary/hired troops (मौल/भृत); aṭavī-bala = troops of forest tribes (वन-जातियों की सेना)
- (10.1) antaḥpura = the inner apartments (अन्तःपुर); śūnyapāla = the śūnyapāla (शून्यपाल); apasarpa = spy (गुप्तचर); mudrā = pass (मुद्रा); rūpājīvā = courtesan (रूपाजीवा); kupya = raw materials (कुप्य); dhanus (measure) = dhanus (धनुष); kārayet = should have (it) done (करवाए)
- (10.2) prasāra = the foraging force (प्रसार); vīvadha = the supply line (वीवध); apasāra = the place of retreat (अपसार); pratigraha = the reserve (प्रतिग्रह); kalatra = the royal household (कलत्र)
- (10.2) nāyaka = the leader (नायक); senā-pati = the commander of the army (सेनापति); bāhu-utsāra = the flank guard (बाहु-रक्षक); sva-bhūmi = one's own ground (अपनी भूमि); abhūmi = unsuitable ground (अनुपयुक्त भूमि)
- (10.2) array (vyūha) names stay as names with 'array' (व्यूह): makara (मकर), śakaṭa (शकट), vajra (वज्र), sarvatobhadra (सर्वतोभद्र), sūcī (सूची); yojana stays yojana (योजन)
- (12.3) sattrin = secret agent (गुप्तचर); tīkṣṇa = assassin (तीक्ष्ण); śūnya-pāla = the regent (शून्यपाल); mahā-mātra = high officer (महामात्र); āṭavika = forest chieftain (आटविक)
- (12.3) kṛtya-pakṣa = the party of the seducible (कृत्य-पक्ष); aparuddha = prince in disfavour (अपरुद्ध); tat-kulīna = member of his family (तत्कुलीन); yuva-rāja = heir-apparent (युवराज); pravāsita = done away with (मारा गया)
- (12.3) pārṣṇim grah = seize the heel (पार्ष्णि पकड़ना), keep the image in both languages; antar-bala = inner army (भीतरी सेना); pratyanta-skandha = frontier contingent (सीमान्त की सैन्य-टुकड़ी)
- (12.1) 'iti X' (a teacher's view) = "..., says X" / "ऐसा X कहते हैं"; 'na iti kauṭilyaḥ' = "No, says Kautilya" / "नहीं, ऐसा कौटिल्य कहते हैं"
- (12.1) dharma-/lobha-/asura-vijayin = righteous / greedy / demonic conqueror (धर्मविजयी/लोभविजयी/असुरविजयी); abhiyoktṛ = attacker (आक्रमणकारी); abhyavapatti = submission (समर्पण)
- (12.1) the four upāyas: sāma = conciliation (साम), dāna = gifts (दान), bheda = dissension (भेद), daṇḍa as upāya = force (दण्ड); as a prakṛti daṇḍa stays army
- (12.1) sandhi = treaty (सन्धि); daṇḍa-/puruṣa-/kośa-/bhūmi-sandhi = treaty of army / men / treasury / land (दण्ड-/पुरुष-/कोश-/भूमि-सन्धि); mantra-yuddha = war of counsel (मन्त्रयुद्ध); kūṭa-yuddha = treacherous warfare (कूटयुद्ध)
- (12.1) gūḍha = secret agent (गुप्तचर); yoga-puruṣa = secret agent (गुप्त पुरुष); tīkṣṇa = fierce men (तीक्ष्ण पुरुष); maula = hereditary troops (मौल सेना); aṭavī (as force) = forest tribes (आटविक); tat-kulīna = kinsman of his family (उसके कुल का व्यक्ति); aparuddha = prince in disfavour (निकाला गया राजकुमार)
- (12.1) rāṣṭra = country (राष्ट्र); skandha-āvāra = camp (सेना-शिविर); rasa (with śastra, agni) = poison (विष); sāra = valuables (बहुमूल्य वस्तुएँ); kupya = raw material (कुप्य); pārṣṇi = rear (पिछला भाग)
- (10.4) the four arms: patti/padāti = foot-soldiers (पैदल सैनिक), aśva/vājin/haya = horses (घोड़े), ratha = chariots (रथ), hasti/dvipa/gaja = elephants (हाथी); catur-aṅga-bala = the fourfold army (चतुरंग सेना); viṣṭi = the labour corps (विष्टि)
- (10.4) yuddha = battle (युद्ध); niveśa = encampment (पड़ाव); bhūmi = ground (भूमि); atiśaya = special advantage (विशेष लाभ); pratyāsāra = place of retreat (पीछे हटने का स्थान)
- (10.4) grahaṇa/mokṣaṇa = capturing/releasing (पकड़ना/छुड़ाना); bhinna-sandhāna = reuniting the broken (ranks) (टूटी हुई सेना को जोड़ना); abhinna-bhedana = breaking the unbroken (ranks) (अटूट सेना को तोड़ना); trāsana = frightening (डराना); audārya = imposing grandeur (भव्यता); bāhu-utsāra = driving off (the enemy) on the flanks (पार्श्वों से खदेड़ना)
- (10.4) vyāyāma in Book 10 = exertion (in fighting) (व्यायाम), not the 6.2 sense 'activity'; vīvadha = supply-line (रसद); āsāra here = reinforcements (सहायक सेना)
