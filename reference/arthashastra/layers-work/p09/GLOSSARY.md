- (9.7) artha = gain (अर्थ) and anartha = loss (अनर्थ), kept in Hindi; where artha is plain wealth (artha-mānābhyām) = wealth (धन); lābha = acquisition (लाभ) in 9.7 where it stands beside artha (9.4 used 'gain' for lābha when artha was absent); āpad-artha = gain that is an adversity (आपत्तिरूप अर्थ); artha-āpad/anartha-āpad = adversity of gain/of loss (अर्थ की आपत्ति/अनर्थ की आपत्ति)
- (9.7) anubandha = sequel (अनुबन्ध), niranubandha = without sequel (अनुबन्ध-रहित); ṣaṭ-varga = sixfold group; a bare iti closing a quoted state ('ito lābha itarato lābha ity ...') is not rendered: quote the phrase, no 'thus/so/इस प्रकार'; sādhayet/sādhaka (of anartha) = overcome/that overcomes (साधे/साधने वाला), sense uncertain
